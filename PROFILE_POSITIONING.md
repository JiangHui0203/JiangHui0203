# Profile positioning notes

This file records the positioning logic behind the public GitHub profile.

## Primary positioning

**LLM Evaluation · Agent / Reasoning Systems · Applied LLM / Research Engineering**

The profile should make the following evidence legible within 20–30 seconds:

1. 3+ years of real industry data experience before graduate school.
2. Current UCAS / CASIA research on adaptive test-time reasoning and evaluation.
3. First-author publications demonstrating independent research execution.
4. Hands-on experimentation, compute accounting, statistical evaluation, and failure analysis.
5. Engineering ability across Python, PyTorch, Transformers, SQL, Linux, Bash, Git, and OpenPAI.

## Target roles

- LLM Evaluation / Benchmark
- Agent Algorithm / Agent Evaluation
- Applied LLM / LLM Application Algorithm
- Research Engineer
- Post-training Data / AI Data
- Reasoning / Test-time Compute

## Positioning constraints

Do not overclaim pre-training, large-scale distributed training, or production Agent experience. The profile should emphasize transferable strengths: rigorous evaluation, data work, reasoning research, experimental design, and research engineering.
